WF Page Transition · v1.6.0 · View Transitions des Browsers

Seitenwechsel mit Übergang.

Jede Seite hier ist eine eigene Datei mit eigener URL. Klick auf ein Projekt: Bild und Titel verwandeln sich in den Kopf der Projektseite, der Rest wechselt mit dem gewählten Effekt. Der Zurück-Button spielt alles rückwärts. Auf den Projektseiten blätterst du unten zum nächsten Projekt.

Mit Morph (Klick auf ein Projekt) bewegt sich nur das Bild, der Effekt gilt dann für Wechsel ohne Morph, z. B. „Alle Projekte“. Das Blättern zwischen Projekten schiebt immer seitlich. Zum Zusehen in Zeitlupe: Zeitlupe an · aus. In Firefox siehst du den normalen Seitenwechsel.

Einbau

  1. Head Code: Inhalt von webflow/head-code.html in Site Settings → Custom Code → Head Code einfügen. Er muss auf jeder Seite liegen, deshalb in den Site-Code, nicht in eine einzelne Seite.
  2. Veröffentlichen. Ab jetzt blendet jeder interne Seitenwechsel weich über.
  3. Optional: am body einen anderen Standard setzen, Teaser und Kopfbereich mit data-page-morph verbinden, Header mit data-page-keep stehen lassen.
<script src="https://cdn.jsdelivr.net/gh/rakete13/wf-page-transition@1.6.0/src/wf-page-transition.min.js"></script>

Attribute

AttributWoWerteWirkung
data-page-transitionbodyfade (Standard), slide, slide-up, zoom, sheet, noneStandard für alle Seitenwechsel
data-page-transitionLink oder ein Element darumwie obenanderer Effekt nur für diesen Link, none = ohne Übergang
data-page-durationbodySekunden, Standard 0.5Dauer
data-page-easebodyGSAP-Namen: power1–power4, sine, expo, circ, back jeweils mit .in, .out, .inOut, dazu linear; oder CSS-Easing wie ease-in-out, cubic-bezier(…)Verlauf der Seitenübergänge
data-page-scale · -dim · -radiusbody0.92 · 0.5 · 24nur sheet: Größe der hinteren Seite, wie stark sie in die Hintergrundfarbe übergeht (0 = aus), Eckenradius in px. Die hintere Seite rundet ihre Ecken ab, die neue kommt mit runden Ecken und wird beim Ankommen eckig. 0 = ohne runde Ecken
data-page-backgroundbodyCSS-Farbe, Standard #000, auch var(--brand)nur sheet: Farbe hinter den Seiten (Ränder, runde Ecken, Abdunkeln)
data-page-order · -splitbodymorph-first (Standard), morph-effect, together · 0.6mit Morph: Standard = nur das Bild bewegt sich, danach ist die Seite sofort da; morph-effect = danach noch der Seiteneffekt (Split = Anteil für den Morph)
data-page-morph-easebodywie data-page-easeEasing des Morphs (sonst data-page-ease)
data-page-morphTeaser-Element und Gegenstück auf der Zielseitefrei, z. B. bild, titelElemente mit gleichem Namen verwandeln sich ineinander
data-page-itemTeaser-Wrapperohne Wertnur nötig, wenn der Teaser kein Collection Item und kein Link Block ist
data-page-keepHeader, FooterName, z. B. headerbleibt beim Wechsel stehen (auf beiden Seiten setzen)
data-page-listCollection List auf der CMS-Vorlage (darf versteckt sein)ohne WertReihenfolge für das Blättern; data-page-loop = nach dem letzten wieder von vorn
data-page-next · data-page-prevLink oder Block mit Linkohne Wertbekommt den Link zum nächsten bzw. vorherigen Eintrag; ohne Nachbar ausgeblendet
data-page-fieldin der Liste und im Next/Prev-BlockName, z. B. titel, bildInhalt wird aus dem Nachbar-Eintrag übernommen (Text oder Bild)
data-page-fallbackbodyfadeBrowser ohne View Transitions blenden die Seite wenigstens ein
